# Q7: whether the cards and the box are translated

Opened 2026-10-12, when the site-translation plan was retired. The operator
has not answered this question. The reading below is in force.

The brief asks for the rulebook in three languages. It does not mention the
cards or the box.

## Reading in force

No. Only the rulebook is translated. The cards and the box stay English, and
so do the pictures of cards inside the rulebook.

## Where it shows

| Consequence | Where |
| --- | --- |
| Card titles and Station names are never translated | The `as-printed` class in `content/glossary/terms.ts` |
| A translated game term carries the English word in brackets at first use, so a reader can match it to the card | [`content/README.md`](../../content/README.md), section The glossary |
| Card pictures in the rulebook PDFs are English | `rulebook/layout/residual-english.md` |

## If the answer differs

Translated cards are a print product, not a change to this repository. The
glossary's second class and its brackets exist only because the cards are
English, and each edition's copy would be revised with them.
