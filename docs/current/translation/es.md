# Spanish translation conventions

The Spanish is neutral, European Spanish. It is a rulebook language, not a site edition: it exists as `rulebook/text/es/` and `content/glossary/es.ts`.

## Address and register

Use **tú** in the rulebook, with singular imperatives: „Baraja las cartas“, „Reparte 3 cartas“. A player is „el jugador“, in the generic masculine that Spanish rulebooks use; plural „los jugadores“. Where a sentence reads as well without it, leave the noun out („Empieza quien haya hecho el viaje más largo“ is also fine). Do not change a named character: Alice is „ella“, Kim and Bob „él“.

## Typography and numbers

Open questions and exclamations with ¿ and ¡. Use angle quotation marks («…») for card text and quoted terms: acciones «Al jugar esta carta». Keep English card titles and Station names exactly as printed (Double Agent, Experimental Borehole, Terran Outpost), without an article of their own and without inflection. Write the decimal comma. Keep rulebook quantities as digits wherever the English rulebook has digits; a page range is written with an en dash („páginas 33–38“). „p. ej.“ stands for „e.g.“.

## Game terms in running text

Follow `content/glossary/es.ts`. Translate game components and action names, then add the printed English word in brackets at the first use on each rulebook sheet: „Suministro (Supply)“, „Acción principal (Main Action)“. Inside a bracket the printed word goes in square brackets: „(tu Estación [Station] + tus Módulos [Modules])“. Omit the bracket where the Spanish word is spelled as printed, as with „Base“. Later uses on the sheet use the Spanish term alone. The test asks for the bracket where the English frame has the term spelled as the glossary lists it, so a capitalised action name („Draw“) needs one and a lower-case verb („draws“) does not.

| English | Spanish | Note |
| --- | --- | --- |
| Station, Module, Agent, Influence | Estación, Módulo, Agente, Influencia | Card types, capitalised; „carta de Estación“, „carta de Influencia“ |
| Credit | crédito | Lower case; „contador de créditos“ for the Credit Counter |
| Supply | Suministro | The face-up cards between the players |
| Base | Base | As printed |
| Orb, Orb half | Esfera, media esfera | Never „orbe“ or „bola“ |
| Shuttle | Lanzadera | The printed word follows in brackets |
| colonist | colono | |
| scientific achievement | logro científico | One noun throughout |
| Main Action | Acción principal | |
| Draft / Draw / Discard | Adquirir / Robar / Descartar | Three different verbs |
| Resell / Build / Flip | Revender / Construir / Voltear | „Voltear“, not „girar“: Modules are rotated when built |
| Steal | Sustraer | „Robar“ is Draw, so stealing needs another verb |
| deck / discard pile | mazo / pila de descarte | „Barajar“ is the verb for shuffling, never the pile |
| hand | mano | |
| victory condition | condición de victoria | |
| rulebook | libro de reglas | |

Action names are infinitives in headings („Robar (Draw)“) and inflect in instructions („Roba 1 carta“). In the sample turn an action done by a player is capitalised as in English („Sustrae“, „Construye“, „Robó“), so the reader sees which verb is the action.

## Reading notes

- The English frame `s23.f08` reads „Shackleton UN-backed Shackleton aims…“; the Spanish says the name once: „Shackleton, con el respaldo de la ONU, aspira…“.
- The English contents page names the section „Variant: Influences“ and its heading „Variant: Influence“. The Spanish keeps the difference: „Variante: Influencias“, „Variante: Influencia“.
- Sheet 10 labels every card slot „JUGADORES“, also the first two that the English prints „2 PLAYER“.
