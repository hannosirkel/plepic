# Italian translation conventions

## Address and register

Use **tu** in the rulebook, with the singular imperative: „Pesca 3 carte“, „Paga il suo costo“. Where the English addresses the reader as a player, the Italian stays impersonal or uses „il giocatore“, „i giocatori“: the masculine plural is the ordinary Italian way to say „players“, and the rules never depend on gender. Where a rule says „turn“ for the whole table, write „il giocatore di turno“. Marketing copy and the shop use **tu** too; legal pages and checkout acknowledgements use **Lei**, written with a capital, as Italian consumer law does. Only the rulebook has Italian text so far.

## Typography and numbers

Use the typographic apostrophe (’) and the accented capital: „È iniziata“, „È il turno di Alice“, never „E’“. Use low guillemets for a quoted card action: «Quando giochi questa carta». Keep English card titles and Station names exactly as printed, in roman type and with their English apostrophes (Laika’s Memorial). Use the Italian decimal comma and a point for thousands (1,5; 1.000); write prices as 19,90 €. Keep rulebook game quantities as digits where the English rulebook has digits, in the same order, and write no other digit: „quattro“, not „4“, where the English says „four“. A noun after a numeral keeps its Italian plural: „1 Credito“, „3 Crediti“.

A card title takes the masculine article in running text („il Depot“, „il Solicitor“, „la Dome“ where the name reads as feminine), or the card type before it where a title contains a glossary word („L’Agente Double Agent“). Plural card titles are not inflected: „2 Rover“.

The six slot labels over the player-count cards on sheet 10 read “Giocatori”, in title case, where English and French print capitals. “GIOCATORI” is wider than the dashed outline of a card at the smallest size the build allows, and the outline is artwork. The credits on sheet 24 use “SQUADRA”, not “team”, and “ALBO D’ORO” for “Wall of Fame”.

## Game terms in running text

Follow `content/glossary/it.ts`. The cards are printed in English, so a translated term names the printed word in round brackets at its first use on each rulebook sheet: „Mercato (Supply)“, „Azioni principali (Main Actions)“. Inside a bracket use square brackets: „(la tua Stazione [Station] + i tuoi Moduli [Modules])“. Omit the bracket where the Italian term is spelled as the card prints it, as with „Base“ and „Shuttle“. Later uses on the same sheet use the Italian term alone. Capitalise a game component and an action name as the English does („Modulo“, „Sfera“, „Crediti“, „Costruire“), and write the common nouns of table talk in lower case („mazzo“, „mano“, „pila degli scarti“).

| English | Italian | Remark |
| --- | --- | --- |
| Station | Stazione | the card type; the Station names stay in English |
| Agent | Agente | not „Spia“ |
| Influence | Influenza, plural Influenze | „carte Influenza“ |
| Module | Modulo, Moduli | |
| Credit | Credito, Crediti | currency |
| Credit Counter | Segnalino Crediti | |
| Supply | Mercato | the face-up display between the players, not a reserve |
| Base | Base | spelled as printed |
| Orb | Sfera, Sfere | an Orb half is a „metà di Sfera“ |
| Shuttle | Shuttle | spelled as printed, invariable in the plural |
| colonist | colono, coloni | |
| scientific achievement | traguardo scientifico | one noun throughout |
| Main Action | Azione principale | |
| deck, hand | mazzo, mano | |
| discard pile | pila degli scarti | one name throughout |
| victory condition | condizione di vittoria | |

The six action names are Italian infinitives in headings and inflect in instructions; the English name stands in brackets at first use only:

| English | Heading | Instruction |
| --- | --- | --- |
| Draft | Prelevare | „Preleva 1 carta“; „devi Prelevare“ |
| Draw | Pescare | „Pesca 1 carta“ |
| Discard | Scartare | „Scarta 1 carta“ |
| Resell | Rivendere | „Rivendi 1 carta“; „devi Rivendere“ |
| Build | Costruire | „Costruisci un Modulo“ |
| Flip | Girare | „Gira la carta Stazione“ |

Keep a plain „prendi“ (take) for moving a card that is not the Draft action: „Prendi 1 carta dal Mercato“ describes what Prelevare does, and the heading names it. Steal is not a glossary term and is translated freely: „Rubare un Modulo“, „Rubare Crediti“.

## Rulebook examples

The English sentences below are from `rulebook/text/en.ts`; the Italian lines demonstrate the glossary.

1. `s06.f03` — “Each player draws 3 cards from the top of the deck into their hand. These are kept secret from the other players.”
   „Ogni giocatore pesca 3 carte dalla cima del mazzo e le tiene in mano. Le tiene segrete agli altri giocatori.“
2. `s06.f04` — “Deal 3 cards plus 1 additional card per player from the deck. Place these face-up between the players to form the Supply.”
   „Prendi dal mazzo 3 carte più 1 carta aggiuntiva per giocatore. Mettile scoperte tra i giocatori a formare il Mercato (Supply).“
3. `s06.f05` — “Give each player a Credit Counter, set to 3 Credits. Use the Credit Counter to track your total Credits.”
   „Dai a ogni giocatore un Segnalino Crediti, impostato su 3 Crediti (Credits). Usa il Segnalino Crediti per tenere il conto dei tuoi Crediti totali.“
4. `s07.f04` — “Each player takes a turn, beginning with the starting player and proceeding clockwise. This continues until a player wins by achieving one or more victory conditions.”
   „Ogni giocatore svolge il proprio turno, a partire dal primo giocatore e proseguendo in senso orario. Si continua finché un giocatore vince soddisfacendo una o più condizioni di vittoria.“
